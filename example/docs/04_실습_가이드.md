# 합성 자료 실습

## 설치 없는 실행

저장소 루트에서 Python 3.11 이상으로 실행합니다. GUI에는 Tkinter가 필요합니다. 외부 패키지와 C 빌드는 필요하지 않습니다.

Windows에서는 루트의 `run.bat`을 더블클릭해 GUI를 열거나 `run.bat analyze ...`로 CLI 인자를 전달합니다.
`test.bat`은 저장소 전용 임시 폴더에서 전체 테스트를 실행합니다. `run-live.bat`은 실제 PC를 읽는 관리자용 실행기이므로 합성 자료 실습에서는 실행하지 않습니다.

```powershell
python example/samples/demo.py
python tools/check_annotated.py
python -m unittest discover -s tests
```

demo.py는 자기 위치를 기준으로 동작하므로 다른 현재 폴더에서도 스크립트 경로를 지정해 실행할 수 있습니다. samples/evidence와 samples/output을 재생성하며 모든 데이터는 코드로 만든 가짜입니다. History SQLite, 압축하지 않은 Prefetch, NTUSER.DAT, 명령 이력을 직접 조립합니다.

예제는 사용자 alice와 `S-1-5-21-1000-2000-3000-1001`, `https://example.com/...`, 고정 날짜를 사용합니다. 사건 파일·공개 챌린지 이미지·실제 PC 파일로 바꾸지 마세요. 출력은 `C:\Evidence\synthetic`을 표시용 기준으로 사용하므로 현재 작업 폴더를 유출하지 않습니다. collected_at/보고서 생성 시각은 고정하고 elapsed_seconds는0으로 둡니다.

## 결과 읽기

11개 이벤트와 누락 Run 키에 대한 정보 진단7개가 나옵니다. 정보 진단은 실제 오류/경고가 아닙니다. 명령 이력 시각은 미상이며 Run 등록을 실행 확정으로 해석하지 않습니다. JSON/HTML·SQLite에는 공통 기록과 관계 후보가, timeline.csv/json/bodyfile에는 타임라인이 들어갑니다. Bodyfile은 지원되는 파일 메타데이터만 담을 수 있어 비어 있을 수 있습니다.

데모 출력은 예제용 정규화가 있으므로 일반 CLI가 원래 출처를 보존하는 동작과 구분하세요. 결과 폴더가 이미 있는 일반 CLI는 덮어쓰지 않습니다.

## CLI 입력 방식

```powershell
python -m log_hunter analyze --input prefetch example/samples/evidence/SETUP.EXE-1A2B3C4D.pf --output outputs/lesson01
python -m log_hunter analyze --auto example/samples/evidence --output outputs/lesson02
python -m log_hunter gui
```

`--auto`는 파일 헤더·폴더 경로·하이브 내용으로 종류를 판단하고 이유를 표시합니다. 예제처럼 일부 키만 가진 작은 하이브는 실제 전체 하이브와 다릅니다. 명시적 입력과 자동 인식 결과가 같다고 가정하지 말고 진단을 확인하세요.

별도로 코드에서 생성한 작은 이미지가 있다면 `analyze --image synthetic.dd --output outputs/image-lesson`으로 읽습니다. E01/raw·고정 VHD와 NTFS 지원/미지원 범위는 루트 README를 확인합니다. `--live C:`는 실제 PC를 읽는 관리자용 기능이므로 이 가짜 자료 실습에서는 실행하지 않습니다. `collect --dll` 옵션은 제거됐습니다.

## 도전 과제

- make_history의 가짜 방문 한 건을 추가하고 결과가 한 건 늘어나는지 확인합니다.
- 알려진 고정 FILETIME을 바꾸고 time_field가 설명하는 시각만 바뀌는지 확인합니다.
- 복사본 바이너리를 중간에서 자르고 ParserError와 partial 상태를 살펴봅니다.
- 서로 다른 SID를 가진 이름 일치 기록이 관계에서 제외되는지 테스트합니다.
- 합성 입력을 다시 만들었을 때 바이트가 동일한지 검사합니다. 파일당10MB/전체example50MB 상한을 유지합니다.
