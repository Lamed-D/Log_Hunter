# 현재 파일별 가이드

원본과 해설판은 `python tools/check_annotated.py`로 비교합니다. 아래 링크의 `# ▶` 주석은 학습 해설입니다.

## 읽기 순서

models → main → pipeline → auto_detect/extract → base/개별 parser → correlation → repository/export/report → ui 순서로 읽습니다.

Python ctypes 수집은 collector/windows.py, 이미지 읽기는 image/ewf.py·volumes.py·ntfs.py, 압축 해제는 parser/xpress.py에서 확인합니다. 자체 C 프로젝트는 없습니다.
