# 시각 기준과 CSV 저장

Log Hunter가 시각을 어떻게 보여 주고 결과를 CSV로 어떻게 저장하는지 정리합니다.

## 모든 시각은 UTC

- 화면(결과 표·타임라인·속성 창·통계)과 보고서, CSV의 시각은 모두 **UTC**입니다. 화면에는 `2022-10-11 08:00:10 UTC`처럼 끝에 `UTC`를 붙입니다.
  분석하는 PC의 시간대로 바꿔 보여 주지 않습니다.
- 날짜 필터(시작·종료)도 UTC 날짜로 해석합니다. 화면에는 "시작 (UTC)", "종료 (UTC)"로 표시됩니다.
- 원래부터 UTC로 저장된 값(Windows FILETIME, 브라우저 시각 등)은 그대로 쓰고, 다른 시간대가 붙은 값은 UTC로 바꿉니다.
  이미 UTC인 값에 시차를 한 번 더 더하지 않습니다.

### "(시간대 미상)"

일부 기록은 시간대 정보 없이 **그 PC의 벽시계 시각**으로 저장됩니다(예: 일부 레지스트리 날짜, 텍스트 로그, 메일의 `-0000` 날짜, FAT 볼륨의 파일 시각, IE 일별 기록의 수정 시각). exFAT 파일 시각은 항목에 UTC 오프셋이 기록돼 있으면 UTC로 바꾸고, 없으면 원래 값 그대로 둡니다.
분석 대상의 시간대 설정을 알면 UTC로 바꾸고 근거를 남깁니다. 알 수 없으면 **UTC인 척하지 않고** 원래 값 뒤에 `(시간대 미상)`을 붙여 보여 줍니다.
이런 값은 UTC 시각과 바로 비교하지 말고 원래 값으로 읽어야 합니다.

### 시각의 의미

같은 기록에도 여러 시각이 있고 뜻이 다릅니다. 표의 **시각의 의미** 열과 속성 창에서 확인합니다. 예:

| 표시 | 뜻 |
| --- | --- |
| 레지스트리 마지막 변경 | 목록 키가 마지막으로 바뀐 시각. 목록 맨 앞 항목에만 해당합니다 |
| 바로가기 파일 생성 (처음 연 시각 후보) | 바로가기가 만들어진 시각. 그 파일을 처음 연 때일 수 있지만 확정은 아닙니다 |
| 바로가기 대상의 접근 시각 (대상 파일 기록) | 바로가기를 만들 때 대상 파일에서 복사해 둔 시각 |
| 검색 결과 페이지 마지막 방문 | 검색어를 입력한 순간이 아니라 결과 페이지를 마지막으로 연 시각 |
| 쿠키 마지막 사용 | 브라우저가 그 쿠키를 마지막으로 보낸 시각 |

## 결과를 CSV로 저장하는 세 가지 방법

| 방법 | 들어가는 기록 | 열 |
| --- | --- | --- |
| **타임라인 내보내기 › CSV** | 현재 필터에 맞는 모든 기록 | 기존 기본 열 + 아래 공통 열 + 다운로드 열 |
| **표를 CSV로 저장** | 지금 표에 보이는 노드·필터의 모든 페이지 | 화면에 보이는 열·순서 그대로(시각은 화면과 같은 UTC 표기) + 뒤에 공통 열 |
| **분류별 CSV 저장** | 분석한 모든 기록 | 새 폴더 안에 분류마다 파일 하나(그 분류의 표 열 + 공통 열)와 `열_설명.csv` |

- 세 방법 모두 같은 함수로 공통 열을 만들므로, 같은 기록은 어느 CSV에서나 공통 열 값이 같습니다.
- 인코딩은 모두 **UTF-8(BOM 포함)**이라 엑셀에서 한글이 깨지지 않습니다.
- `=`, `+`, `-`, `@`로 시작하는 값은 앞에 `'`를 붙여 스프레드시트가 수식으로 실행하지 않게 합니다.
- 이미 있는 파일·폴더는 덮어쓰지 않습니다. 원본 증거와 같은 폴더에는 저장하지 않습니다.

### 공통 열

| 열 | 뜻 |
| --- | --- |
| `artifact` / `artifact_label` | 기록 종류(내부 이름 / 쉬운 이름) |
| `action` | 무슨 일(내부 이름) |
| `timestamp_utc` | 시각(UTC, ISO 8601). 시간대를 모르면 비움 |
| `time_meaning` | 시각의 의미 |
| `time_basis` | 시각의 근거. 예: `key_lastwrite`(레지스트리 키 수정 시각), `로컬 기록 → UTC 환산, 시간대 근거: …`(분석 대상의 시간대 설정으로 환산), `시간대 미상`. 비어 있으면 기록의 원래 시각을 그대로 쓴 것 |
| `timestamp_raw_local` | 시간대를 몰라 UTC로 바꾸지 않은 원래 시각 |
| `user` / `sid` | 사용자 이름 / SID |
| `target` | 대상(파일·프로그램·주소) |
| `target_key` | 같은 대상 묶음 키(최근 파일·폴더 기록) |
| `source_path` | 이미지 안 원본 위치 |
| `source_locator` | 원본 안 위치(레지스트리 키 경로, 내부 위치, 오프셋) |
| `status` | 상태 |
| `details_json` | 세부 정보 원문(JSON) |

웹 다운로드는 `download_save_path`(저장 경로), `download_url`(처음 요청한 주소), `final_url`(파일을 내려 준 주소),
`referrer_url`(참조 페이지), `tab_url`, `tab_referrer_url`, `site_url`, `download_state` 열이 더 있습니다. 방문 기록은 `referrer_url`만 채웁니다.

기존 CSV를 읽던 도구가 깨지지 않도록 예전 열 이름과 순서는 그대로 두고 새 열은 뒤에 붙였습니다.

## 큰 분석 열기

- 저장한 분석(`case.sqlite`)을 열면 저장 파일의 색인에서 **처음 1,000건과 전체 건수를 먼저** 보여 줍니다(상태 줄 "빠른 보기").
  불러오는 동안에도 트리 노드·필터·이전/다음 페이지·시각(또는 사용자 SID) 열 정렬은 저장 파일에서 바로 조회합니다.
  전체를 불러오면 다른 열 정렬과 속성 창까지 쓸 수 있는 평소 화면으로 바뀝니다. 예전 버전으로 저장한 분석은 빠른 보기 없이 전체를 불러온 뒤 보입니다.
- **통계/시각화** 탭은 기록 전체를 읽어 계산하므로, 그 탭을 처음 열 때 계산합니다.
- 결과 표는 한 번에 1,000행씩 보이고 **이전/다음**으로 넘깁니다. 정렬과 CSV 저장은 모든 페이지에 적용됩니다.
