# 데이터 규칙: 예제·테스트는 가짜 데이터만

저장소(`tests/`, `example/`, `docs/`, 스크린샷, PR·이슈 본문 포함)에 들어가는 모든 데이터는 **코드로 만든 가짜(합성) 데이터**여야 합니다.
실제 PC·실제 사건·실제 사용자에서 나온 데이터는 한 바이트도 커밋하지 않습니다.

## 1. 진짜 데이터로 보는 것 (커밋 금지)

- 실제 PC에서 복사한 하이브·이벤트 로그·Prefetch·`$MFT`·변경 저널·SRUM·브라우저 DB·LNK·Jump List·휴지통 파일·메모리 덤프
- 실제 디스크 이미지(E01·dd·VHD 등)와 그 분석 결과(`case.sqlite`, `report.*`, `timeline.*`, `image_manifest.json`)
- **작업하는 PC 자신에서 나온 모든 것**: 이 PC 직접 분석·수집 결과, 그 화면을 찍은 스크린샷
- 실제 식별 정보: 사용자명·컴퓨터 이름·SID·이메일·IP·MAC·장치 시리얼·Wi-Fi 이름·방문 URL·파일 경로
- 인터넷의 공개 포렌식 샘플·챌린지 데이터

## 2. 가짜 데이터 만드는 법

- **코드로 생성**합니다. 테스트는 기존 빌더(`tests/test_image.py`, `tests/fixtures/` 생성기)를 재사용·확장하고, 예제는 생성 스크립트로 만듭니다.
  생성 스크립트가 없는 바이너리는 커밋하지 않습니다.
- **재현 가능하게**: 난수 시드와 시각을 고정해 다시 만들어도 같은 바이트가 나오게 합니다.
- 가짜 값은 아래만 씁니다(`tests/test_repo_hygiene.py`가 검사):

  | 항목 | 쓸 값 |
  | --- | --- |
  | 사용자명 | `alice`, `bob`, `analyst`, `testuser` |
  | SID | `S-1-5-21-1000-2000-3000-1001`처럼 앞부분 고정 + 계정 번호(RID), 또는 기존 테스트의 `S-1-5-21-1-2-3-1001` |
  | 컴퓨터 이름 | `DESKTOP-TEST01`, `WORKSTATION-01` |
  | 도메인·이메일·URL | `example.com`, `example.org`, `*.test`, `alice@example.com`, `https://example.com/...` |
  | IP | 문서용 대역 `192.0.2.x`, `198.51.100.x`, `203.0.113.x`, IPv6 `2001:db8::/32` |
  | MAC·시리얼 | `00-00-5E-00-53-xx`, `TESTSERIAL0001` 같은 명백한 가짜 |
  | 경로 | `C:\Users\alice\...`, `C:\Evidence\...` |
  | 시각 | 고정 날짜(예: 2020-12-30, 2024-01-01) |

- 실제 Windows 형식을 흉내 낼 때도 **구조만** 따르고 내용은 가짜 값으로 채웁니다. 실제 파일을 복사해 일부만 바꾸지 않습니다.

## 3. 커밋해도 되는 가짜 데이터

- `example/**`와 `tests/fixtures/**`의 합성 샘플 증거, 그 분석 결과, 가짜 데이터로 찍은 스크린샷은 커밋합니다.
- 조건: 생성 스크립트로 다시 만들 수 있음, 값이 전부 2절 규칙, 4절 점검 통과, 파일 하나 10MB 이하·`example/` 전체 50MB 이하.
- 판단 기준은 **형식이 아니라 출처**입니다(코드로 만든 가짜 → 허용, 실제에서 나온 것 → 금지).

## 4. 커밋 전 점검

1. 추가·변경 파일 확인: `git diff --cached --stat`.
2. 바이너리·증거 형식 파일은 생성 스크립트로 다시 만들어 같은 바이트인지 확인.
3. 전체 테스트(위생 테스트 포함) 통과, `python tools/check_confidential.py staged` 통과.
4. 걸리면 스테이징에서 빼고 가짜 데이터로 다시 만듭니다. **이미 푸시했다면 혼자 처리하지 말고 채팅으로 사용자에게 알립니다**
   (기록에서 지우려면 force-push가 필요하고, 그건 사용자만 결정).

## 5. 스크린샷·PR·이슈 본문

가짜 데이터로 연 화면만 찍고, 창 제목·경로·사용자·컴퓨터 이름이 실제 값이면 쓰지 않습니다. 커밋 전에 이미지를 직접 열어 확인합니다.
실제 PC에서 돌린 출력은 이름·경로·식별자를 가린 요약만 씁니다. 참고 도구를 실행한 비교 결과는 `outputs/`에만 둡니다.
