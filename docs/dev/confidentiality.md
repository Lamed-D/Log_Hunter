# 비공개 자료 규칙

이 프로젝트는 외부 포렌식 도구와 그 소스·자료를 **기능만 참고**합니다. 참고한 내용과 개인정보는 저장소 기록에 남기지 않습니다.

## 1. 남기지 않는 것

커밋(파일·메시지), 브랜치 이름, PR 제목·본문, 이슈, 리뷰 코멘트, 문서, 화면 문구 어디에도 다음을 쓰지 않습니다.

- 참고한 외부 도구·저장소의 이름, 주소, 소유자, 로컬 경로, 플러그인·파일 이름
- 참고 자료의 코드·정규식·데이터 표·문구를 그대로 옮긴 것(내용을 이해한 뒤 공개 사양·공식 문서를 근거로 새로 작성합니다)
- "다른 도구와 비교해 보니", "참고 도구에서는" 같은 비교 언급 — 이슈·PR은 **일반적인 개선·버그 수정**으로만 씁니다
- 개인정보(실명, 계정, 이메일, 사용자 폴더 경로, 컴퓨터 이름)와 비밀 정보(토큰, 비밀번호)

근거가 필요하면 "공개 형식 문서", "Windows 공식 문서"처럼 일반적인 이름으로 적고, 공개된 공식 문서는 공개 URL로만 인용합니다.

## 2. 참고 자료를 두는 곳

- 참고 자료는 저장소 **밖**에 두거나, 저장소 안이라면 `.private/`, `refs/`처럼 `.gitignore`가 막는 폴더에 둡니다.
- 특정 참고 자료 이름을 무시 목록에 넣을 때는 공개되는 `.gitignore`가 아니라 **`.git/info/exclude`** 에 적습니다.
- 참고 도구를 실행해 비교한 결과·메모는 `outputs/`(git 무시)에만 둡니다.

## 3. 자동 검사

- `tools/check_confidential.py`가 커밋 내용·커밋 메시지·푸시에서 비공개 낱말을 찾으면 막습니다.
- 낱말 목록은 저장소에 올리지 않는 **`.confidential-terms`** 파일(작업 폴더 맨 위, 한 줄에 하나, `#` 주석)에 있습니다.
  목록 자체도 비밀이므로 문서·코드·커밋에 그 내용을 옮겨 적지 않습니다. 저장소 관리자에게 비공개 경로로 받습니다.
- `tests/test_repo_hygiene.py`가 추적 파일 전체에서 참고 도구 이름과 실제 식별 정보(가짜 값 규칙 밖의 경로·SID·IP 등)를 검사합니다.
- 훅 설치(작업 폴더마다 한 번, `python tools/setup_agent.py <이름>`이 대신 해 줌):

  ```bash
  git config core.hooksPath tools/hooks
  ```

- 훅을 끄거나 우회(`--no-verify`)하지 않습니다. 검사가 막으면 내용을 고칩니다.
- 푸시·병합 전에 직접 확인할 때:

  ```bash
  python tools/check_confidential.py range origin/main..HEAD
  ```

## 4. 이미 올라간 기록에서 발견하면

혼자 기록을 고쳐 쓰거나 force-push하지 않습니다. 현재 트리는 새 커밋으로 고치고, 과거 기록 처리는 `to:user` 이슈 대신
**채팅으로 사용자에게만** 알립니다(이슈에 쓰면 그 내용이 다시 기록에 남기 때문).
