- zipapp는 소스 폴더 밖에서 실행해 결과 파일 생성·오류 종료 코드 1 보존을 검증.

## 수집과 원본 보존

컴파일된 확장 대신 표준 라이브러리 ctypes로 공유 읽기·레지스트리 저장·이벤트 내보내기를 호출한다.
선언한 API는 인자·반환 타입을 지정하고 핸들을 finally에서 닫는다. 백업 권한은 이전 상태로 복원한다.
공유 읽기 실패 시 기존 NTFS 직접 읽기로 대체한다. 스냅샷 구현은 복잡한 COM 수명·권한 의존을 줄이기 위해 제거했다.
브라우저 DB와 보조 파일은 한 볼륨 세션에서 읽지만 실행 중 원본의 시점 일관성은 보장하지 않는다.
manifest의 `point_in_time_consistent`는 false이며 원본 변화 가능성 안내를 기록한다.
실제 관리자 볼륨 읽기·레지스트리 저장·이벤트 내보내기는 검증하지 않았다. 일반 파일 수집은 합성 파일로 실제 Windows API를 검증했다.
