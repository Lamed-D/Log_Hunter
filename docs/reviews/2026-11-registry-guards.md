## 경계와 해석

키 셀은 한 번만 순회하고 폴더 기록 순회에는 별도 깊이 상한을 적용한다. 손상 형제 키는 건너뛰고 파서 오류 콜백으로 키별 한 번만 진단한다.
현대 LOG는 512바이트 기본 블록과 HvLE 항목으로 해석한다. 두 Marvin32 해시·헤더 체크섬·파일 타입·시퀀스·512바이트 페이지 정렬·범위를 검증한다.
독립 Microsoft 공개 해시 검증값(abc, 지정 seed)을 확인했다. LOG1/LOG2 연속 항목·동일 순번 충돌·중간 손상·시퀀스 순환·가짜 bins 크기를 검증했다.
충돌 항목을 임의 선택하지 않으며 손상 항목 앞의 검증된 부분만 적용한다. 적용 경고는 파이프라인에도 전달한다.
복구 사본은 원본의 실제 크기보다 최대 64MiB만 성장한다. 헤더의 위조 크기가 이 상한을 늘리지 못한다. 복구 후 헤더 체크섬도 갱신한다.
기본 블록 자체의 체크섬이 손상된 하이브의 헤더 추정 복구와 구형 DIRT 형식은 지원하지 않는 이유를 안내한다.
실제 하이브/LOG·관리자 환경은 검증하지 않았다. 원본 파일·LOG는 수정하지 않는다.
