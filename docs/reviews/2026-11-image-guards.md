## 변경과 한계

경로 구분자·예약 장치 이름을 정리하고 출력 루트 포함 여부를 검사한다. 재귀 디렉터리는 MFT 레코드/패턴 위치별로 한 번만 순회한다.
이름 충돌과 생성 경합에서 이전 사본을 삭제하지 않는다. NTFS 논리 크기는 run과 이미지 용량으로 제한하며 잘림을 경고한다.
이미지 끝을 넘는 읽기의 빈 부분을 채워 뒤의 오프셋이 당겨지지 않게 한다. 잘못된 EWF 생성 실패 시 열린 핸들을 닫는다.
EWF 메타데이터의 압축 입력·확장 출력은 1MiB, 테이블은 16MiB, 청크는 16MiB, 한 번에 메모리로 읽는 NTFS 속성은 64MiB로 제한한다.
정상 범위를 넘는 메타데이터는 명시적 오류를 반환한다. 일반 파일 복사는 블록 단위로 계속 처리한다.
희소 파일의 논리 크기가 전체 이미지 용량보다 큰 경우 안전 상한으로 잘리고 경고가 남는다.
실제 손상 이미지·실제 증거는 검증하지 않았다. GUI·보고서·출력 내부 키 변경은 없다.
